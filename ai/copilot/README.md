Copilot suggested `$(uptime)` as soon as I started to type `echo "Uptime:`.

This script prints the current system uptime.

Run it from the repository root:

```bash
chmod +x ai/copilot/copilot_test.sh
./ai/copilot/copilot_test.sh
```

Or run it directly with bash:

```bash
bash ai/copilot/copilot_test.sh
```

Example output:

```bash
Uptime:  up 1 day, 2:34,  1 user,  load average: 0.12, 0.08, 0.05
```
